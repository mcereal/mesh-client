title: Controls
description: What each button on the Brick does, on every tab and in the keyboard.
---

MeshClient is built around the d-pad and face buttons. The bar at the bottom of the screen
always shows the buttons that do something right now, so you rarely need this page. It's here
for when you want to know everything a button can do.

The keys below are the ones **printed on the Brick**. A Miyoo Mini Plus has the same buttons,
and they do the same things. On a desktop, the same keys map to a keyboard or a game
controller.

## Everywhere

| Button | What it does |
|---|---|
| **Left / Right**, **L1 / R1** | switch tab |
| **Up / Down** | move the cursor; hold to keep scrolling, faster after a few rows |
| **L2 / R2** | jump a page of rows, or a whole group on screens drawn as cards |
| **A** | act on the row under the cursor |
| **B** | go back; hold it to go all the way back to the tab's own list |
| **SELECT** | help for what's on screen |
| **MENU** | quit |

## Per tab

| Tab | **Y** | **X** | Other |
|---|---|---|---|
| **Messages** | write a message | delete a conversation (press twice) | in a conversation: **X** reacts with an emoji, **START** resends a failed message |
| **Nodes** | message the node | pin a node to the top | **A** opens a node's details |
| **Map** | zoom out | zoom in | d-pad pans, **START** fits everything, **L2 / R2** switch to the list of places |
| **Radio** | forget a pairing (twice, in the device list) | disconnect (twice, in the device list); refresh on the other pages | **A** on a card's button opens that page |
| **Settings** | save the section | refresh from the radio | **A** edits a row |

## The keyboard

The keyboard opens whenever you're typing: a message, a search, an address or a setting. It
works like a games console keyboard.

| Button | What it does |
|---|---|
| **d-pad** | move around the keys |
| **A** | type the key under the cursor |
| **X** | backspace |
| **Y** | space |
| **START** | send, or finish |
| **B** | close the keyboard, keeping what you typed |
| **L2 / R2** | move the text cursor one character, to fix a typo without deleting the rest |
| **L1 / R1** | change the key set: `abc`, `ABC`, symbols, then three pages of emoji |

`ABC` gives you one capital letter and then returns to `abc`. To lock capitals on, for a
callsign, switch back to `ABC` straight after typing a capital. The bottom-left key also steps
through the key sets, so you can reach everything without the shoulder buttons.

To throw a draft away, use the **✕** key on the grid.
